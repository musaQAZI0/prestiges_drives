# Prestige Drives

Next.js website for Prestige Drives, including the fleet, services, about, and contact pages.

## Local development

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
npm start
```

## Vercel

Import this GitHub repository into Vercel as a Next.js project. The application is at the repository root; use the default install and build settings.

Optional contact channels are listed in `.env.example`. Configure verified values in Vercel environment variables or a local `.env.local` file. Local environment files, dependencies, and build output are excluded from Git.
