# Official fleet image sources

Verified/downloaded: 16 November 2026. Full source page, asset URL and model mapping are recorded in `sources.json`. Original files are retained here; production WebP files are in `public/assets/optimized/fleet/official/`.

Manufacturer images are model references, not photographs of the actual rental units. Colour, model year and equipment can differ. Source availability does not grant a commercial-use licence; confirm permission with each rights holder before publishing these assets. No Lexus USA pressroom images were used because its stated terms prohibit advertising and commercial use.

## Main fleet coverage

All 31 main-fleet entries now use verified official manufacturer or authorized dealer source images. Honda BR-V uses Honda Shahrah-e-Faisal; Toyota GLI uses Toyota Islamabad. Civic X uses a US-market sedan brochure and LC 200 uses a 2007 archive reference; the corresponding model-year/market notes are shown on their detail pages.

Brochure images were extracted directly without AI generation. Crop coordinates are recorded in `sources.json` and preserved by `optimize-images.mjs`.

The separate wedding/service catalogue still uses its previous illustrations.

`lib/official-fleet-images.ts` maps the verified manufacturer assets into the fleet. Source links appear below the vehicle detail gallery.
