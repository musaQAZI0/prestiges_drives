# Fleet studio collection

29 AI-styled images cover the 31 main fleet entries. Generated using the built-in imagegen tool, individually from each official reference, with the LC 200 studio image as the shared lighting and composition reference.

Style: charcoal cyclorama, matte floor, soft overhead lighting, restrained champagne rim light, centered complete vehicle in a left-facing front three-quarter view, landscape 3:2 framing.

- Full-resolution PNGs: this directory.
- Production WebPs: `public/assets/optimized/fleet/studio/`.
- Fleet mapping: `lib/studio-fleet-images.ts`.
- Prompt recipe and per-model subjects: `prompts.json`.
- Collection contact sheet: `preview.webp`.
- Official input references and provenance: `public/assets/fleet/official/`.

These are AI-styled model illustrations, not photographs of rental inventory. Small trim and badge details can differ; source model-year notes remain attached to the fleet entries. Official originals have been retained without replacement.
